## Dağcan İş Takip v0.2.0

🇬🇧 **Bilingual release.** The whole app — UI, tray menu, notifications and error messages — now works in English and Turkish.

**New**
- Overview dashboard with KPIs and upcoming deadlines
- Command palette (`⌘K` / `Ctrl+K`)
- Task checklists and per-task time tracking
- Strong password generator in the vault
- AI Studio: Change Request (RFC/CAB) and Post-Incident Report modes
- Settings: board JSON backup/restore, encrypted vault backup

**Install:** download the `.dmg` (macOS) or `.msi` / `.exe` (Windows) below. Builds are not code-signed yet — on macOS right-click → Open, on Windows choose *More info → Run anyway*.

🇹🇷 **Çift dilli sürüm.** Arayüz, tepsi menüsü, bildirimler ve hata mesajları dahil tüm uygulama artık Türkçe ve İngilizce çalışıyor.

**Yenilikler**
