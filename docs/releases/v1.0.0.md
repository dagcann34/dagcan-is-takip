## Kanvault 1.0 — Task & Security Hub

🇬🇧 **Dağcan İş Takip is now Kanvault** — free, open source, developed by Dağcan Nural.
- **Time Machine**: go back to any day and see the board as it was, plus that day’s activity
- **Dashboard Studio**: date-range reports in Neon HUD, Whiteboard, Chalkboard, Executive and Blueprint themes (PNG/PDF)
- **Hardened security**: board & history encrypted at rest (OS keychain key), screenshot protection, copy/select blocking, per-window permissions, brute-force back-off
- New logo, polished Neon Grid design, bilingual About page

🇹🇷 **Dağcan İş Takip artık Kanvault**: ücretsiz, açık kaynak, Dağcan Nural tarafından geliştirildi.
- **Zaman Makinesi**: herhangi bir güne dönüp panonun o günkü hâlini ve o günün etkinliklerini görebilirsin
- **Dashboard Stüdyosu**: tarih aralığı raporları; Neon HUD, Beyaz Tahta, Kara Tahta, Yönetici ve Blueprint temaları (PNG/PDF)
- **Sertleştirilmiş güvenlik**: pano ve geçmiş diskte şifreli (anahtar işletim sistemi anahtar zincirinde), ekran görüntüsü koruması, kopyalama/seçme engeli, pencere bazında izinler, kaba kuvvet koruması
- Yeni logo, cilalanmış Neon Grid tasarımı, iki dilli Hakkında sayfası

**Install / Kurulum:** `.dmg` (macOS) · `.exe` / `.msi` (Windows). Not code-signed yet — on macOS right-click → Open / henüz imzasız; macOS'ta sağ tık → Aç.
